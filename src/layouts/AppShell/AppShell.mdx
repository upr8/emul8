AppShell provides the main application layout structure with header, sidebar, main content, and footer areas.

## Features

- **Complete app structure** - Header, Sidebar, Main, Footer components
- **Flexible composition** - Use only the parts you need
- **Responsive ready** - Sidebar widths and sticky header options
- **Left or right sidebar** - Position sidebar on either side
- **Multiple sidebars** - Support for double-sidebar layouts

## Usage

```tsx
import { AppShell } from "emul8";

// Basic app layout
<AppShell className="h-screen">
  <AppShell.Header>
    <Logo />
  </AppShell.Header>
  <AppShell.Body>
    <AppShell.Sidebar>
      <Navigation />
    </AppShell.Sidebar>
    <AppShell.Main>
      <Content />
    </AppShell.Main>
  </AppShell.Body>
  <AppShell.Footer>
    <Copyright />
  </AppShell.Footer>
</AppShell>

// Without sidebar
<AppShell>
  <AppShell.Header>
    <TopNav />
  </AppShell.Header>
  <AppShell.Main maxWidth="lg" className="mx-auto">
    <Content />
  </AppShell.Main>
</AppShell>

// Right sidebar
<AppShell>
  <AppShell.Body>
    <AppShell.Main>
      <Content />
    </AppShell.Main>
    <AppShell.Sidebar position="right">
      <DetailsPanel />
    </AppShell.Sidebar>
  </AppShell.Body>
</AppShell>
```

## Styling

AppShell is a **pure structural component** - it handles only layout concerns (positioning, sizing, spacing) without any color or theme dependencies. Apply colors via `className`:

```tsx
// Add background and border colors
<AppShell.Header className="bg-white border-gray-200 dark:bg-gray-900 dark:border-gray-800">
  <Logo />
</AppShell.Header>

<AppShell.Sidebar className="bg-gray-50 border-gray-200 dark:bg-gray-800 dark:border-gray-700">
  <Navigation />
</AppShell.Sidebar>
```

## When to Use

- Dashboard applications with side navigation
- Admin panels with header and sidebar
- Documentation sites with table of contents
- Any application needing consistent page structure
