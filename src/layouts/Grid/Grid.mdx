Grid creates an auto-filling responsive grid with optional responsive gap.

## Features

- **Auto-fill** - Items automatically fill available space
- **Responsive** - Wraps when items can't maintain minimum width
- **Flexible minimum** - Control minimum item width
- **Responsive gap** - Object syntax for adaptive spacing
- **Fixed columns** - Optional fixed column count

## Usage

```tsx
import { Grid } from "emul8";

// Basic grid with default 250px minimum
<Grid gap="lg">
  <Card />
  <Card />
  <Card />
  <Card />
</Grid>

// Grid with responsive gap
<Grid gap={{ base: 'sm', md: 'md', lg: 'lg' }} min="280px">
  <ProductCard />
  <ProductCard />
  <ProductCard />
</Grid>

// Fixed 3-column layout
<Grid columns={3} gap="md">
  <Item />
  <Item />
  <Item />
</Grid>
```

## Responsive Gap

Use object syntax for adaptive spacing across breakpoints:

```tsx
// Object syntax for responsive gap
<Grid gap={{ base: 'sm', md: 'md', lg: 'lg' }} min="200px">
  {/* gap-2 (mobile) → md:gap-4 (tablet) → lg:gap-6 (desktop) */}
</Grid>

// No base gap, starts at md breakpoint
<Grid gap={{ md: 'md', lg: 'lg' }}>
  {/* No gap on mobile, md:gap-4, lg:gap-6 */}
</Grid>
```

<Markdown>
{`
| Notation | Description |
| -------- | ----------- |
| \`"md"\` | Static gap (gap-4) at all sizes |
| \`{ base: 'sm', md: 'md' }\` | gap-2 base, md:gap-4 at medium screens |
| \`{ base: 'sm', md: 'md', lg: 'lg' }\` | Grows with each breakpoint |
| \`{ md: 'md', xl: 'lg' }\` | No base, starts at md breakpoint |
`}
</Markdown>

## How It Works

The Grid uses CSS Grid's `auto-fill` with `minmax()`:

```css
grid-template-columns: repeat(auto-fill, minmax(min(250px, 100%), 1fr))
```

- Items expand to fill available space equally
- When items would be narrower than `min`, they wrap to next row
- The `min(min, 100%)` ensures items never overflow on narrow screens

## Best Practices

### Product Grids

Use responsive gap for e-commerce layouts:

```tsx
<Grid gap={{ base: 'sm', md: 'md', lg: 'lg' }} min="280px">
  {products.map(product => (
    <ProductCard key={product.id} {...product} />
  ))}
</Grid>
```

### Image Galleries

Tighter gaps for visual grids:

```tsx
<Grid gap={{ base: 'xs', md: 'sm' }} min="200px">
  {images.map(img => (
    <img key={img.id} src={img.src} alt={img.alt} />
  ))}
</Grid>
```

### Dashboard Widgets

Larger gaps for distinct cards:

```tsx
<Grid gap={{ base: 'md', lg: 'lg' }} min="300px">
  <StatsCard />
  <ChartCard />
  <ActivityCard />
</Grid>
```

### Mobile-First Approach

Start with smaller gaps on mobile, increase on larger screens:

```tsx
// Tight on mobile, spacious on desktop
<Grid gap={{ base: 'xs', sm: 'sm', md: 'md', lg: 'lg' }}>
  {items.map(item => <Card key={item.id} {...item} />)}
</Grid>
```
