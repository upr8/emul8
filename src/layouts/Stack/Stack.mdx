Stack arranges items vertically or horizontally with consistent, responsive spacing.

## Features

- **Flexible direction** - Vertical or horizontal stacking
- **Responsive gap** - Object syntax for adaptive spacing
- **Split layout** - Push content to opposite ends with `splitAfter`
- **Dividers** - Optional divider elements between items
- **Alignment** - Control cross-axis and main-axis alignment

## Usage

```tsx
import { Stack } from "emul8";

// Vertical stack (default)
<Stack gap="lg">
  <div>Item 1</div>
  <div>Item 2</div>
</Stack>

// Horizontal stack with responsive gap
<Stack direction="horizontal" gap={{ base: 'sm', md: 'md', lg: 'lg' }} align="center">
  <Icon />
  <span>Label</span>
</Stack>

// Form with adaptive spacing
<Stack gap={{ base: 'sm', md: 'md' }}>
  <FormField label="Email" />
  <FormField label="Password" />
  <Button>Submit</Button>
</Stack>
```

## Responsive Gap

Use object syntax for adaptive spacing across breakpoints:

```tsx
// Object syntax for responsive gap
<Stack gap={{ base: 'sm', md: 'md', lg: 'lg' }}>
  {/* gap-2 (mobile) → md:gap-4 (tablet) → lg:gap-6 (desktop) */}
</Stack>

// Horizontal nav with responsive spacing
<Stack direction="horizontal" gap={{ base: 'xs', md: 'sm', lg: 'lg' }}>
  <NavItem />
  <NavItem />
  <NavItem />
</Stack>
```

<Markdown>
{`
| Notation | Description |
| -------- | ----------- |
| \`"md"\` | Static gap (gap-4) at all sizes |
| \`{ base: 'sm', md: 'md' }\` | gap-2 base, md:gap-4 at medium screens |
| \`{ base: 'sm', md: 'md', lg: 'lg' }\` | Grows with each breakpoint |
| \`{ md: 'md', xl: 'lg' }\` | No base, starts at md breakpoint |
`}
</Markdown>

## Split Layout

The `splitAfter` prop pushes content after a specific index to the opposite end:

```tsx
// Header at top, footer at bottom
<Stack splitAfter={0} className="h-full">
  <header>Title</header>
  <main>Content pushed down</main>
  <footer>Footer at bottom</footer>
</Stack>

// Combine with responsive gap
<Stack splitAfter={0} gap={{ base: 'sm', md: 'md' }} className="h-screen">
  <Header />
  <MainContent />
  <Footer />
</Stack>
```

## Dividers

Add visual separators between items:

```tsx
// With divider
<Stack gap="md" divider={<Divider />}>
  <div>Section 1</div>
  <div>Section 2</div>
  <div>Section 3</div>
</Stack>

// Divider with splitAfter
<Stack gap="md" divider={<Divider />} splitAfter={0}>
  <Header />
  <Content />
  <Footer />
</Stack>
```

## Props

<Markdown>
{`
| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| \`direction\` | \`"vertical" \\| "horizontal"\` | \`"vertical"\` | Stack direction |
| \`gap\` | \`"none" \\| "xs" \\| "sm" \\| "md" \\| "lg" \\| "xl" \\| "2xl"\` or responsive object | \`"md"\` | Space between items |
| \`align\` | \`"start" \\| "center" \\| "end" \\| "stretch" \\| "baseline"\` | - | Cross-axis alignment |

| \`splitAfter\` | \`number\` | - | Push items after this index to opposite end |
| \`divider\` | \`ReactNode\` | - | Element to insert between items |

## Best Practices

### Form Layouts

Use responsive gap for forms - tighter on mobile, more breathing room on desktop:

```tsx
<Stack gap={{ base: 'sm', md: 'md' }}>
  <TextField label="Name" />
  <TextField label="Email" />
  <TextArea label="Message" />
  <Button>Submit</Button>
</Stack>
```

### Navigation Headers

Horizontal stack with responsive gap for nav items:

```tsx
<Stack direction="horizontal" gap={{ base: 'sm', md: 'md', lg: 'lg' }} align="center">
  <Logo />
  <nav>
    <Stack direction="horizontal" gap={{ base: 'xs', md: 'sm' }}>
      <NavLink>Home</NavLink>
      <NavLink>About</NavLink>
      <NavLink>Contact</NavLink>
    </Stack>
  </nav>
</Stack>
```

### Card Content

Stack content within cards with consistent spacing:

```tsx
<Card>
  <Stack gap={{ base: 'sm', md: 'md' }}>
    <CardHeader />
    <CardBody />
    <CardFooter />
  </Stack>
</Card>
```

### Page Layouts with Split

Combine responsive gap with splitAfter for full-page layouts:

```tsx
<Stack splitAfter={1} gap={{ base: 'md', lg: 'lg' }} className="min-h-screen">
  <Header />
  <main className="flex-1">
    <Stack gap={{ base: 'sm', md: 'md' }}>{/* Content */}</Stack>
  </main>
  <Footer />
</Stack>
```
