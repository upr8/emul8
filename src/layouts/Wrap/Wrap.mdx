Wrap creates a flex container that wraps its children naturally with responsive gap support.

## Features

- **Natural wrapping** - Items wrap to next line when space runs out
- **Responsive gap** - Object syntax for adaptive spacing
- **Alignment options** - Control cross-axis and main-axis alignment
- **Slot support** - Render as child element with `asChild`

## Usage

```tsx
import { Wrap } from "emul8";

// Tag cloud with responsive gap
<Wrap gap={{ base: 'xs', md: 'sm' }}>
  <Tag>JavaScript</Tag>
  <Tag>TypeScript</Tag>
  <Tag>React</Tag>
  <Tag>Vue</Tag>
</Wrap>

// Centered wrapping button group
<Wrap gap={{ base: 'sm', md: 'md' }} justify="center">
  <Button>Edit</Button>
  <Button>Delete</Button>
  <Button>Share</Button>
</Wrap>

// Filter chips with responsive spacing
<Wrap gap={{ base: 'xs', sm: 'sm', md: 'md' }}>
  {filters.map(f => <Chip key={f.id}>{f.name}</Chip>)}
</Wrap>
```

## Responsive Gap

Use object syntax for adaptive spacing across breakpoints:

```tsx
// Object syntax for responsive gap
<Wrap gap={{ base: 'xs', md: 'sm', lg: 'lg' }}>
  {/* gap-1 (mobile) → md:gap-2 → lg:gap-6 */}
</Wrap>

// Compact on mobile, spacious on desktop
<Wrap gap={{ base: 'xs', sm: 'sm', md: 'md' }}>
  <Tag>One</Tag>
  <Tag>Two</Tag>
  <Tag>Three</Tag>
</Wrap>
```

<Markdown>
{`
| Notation | Description |
| -------- | ----------- |
| \`"sm"\` | Static gap (gap-2) at all sizes |
| \`{ base: 'xs', md: 'sm' }\` | gap-1 base, md:gap-2 at medium screens |
| \`{ base: 'xs', sm: 'sm', md: 'md' }\` | Grows with each breakpoint |
| \`{ md: 'sm', lg: 'lg' }\` | No base, starts at md breakpoint |
`}
</Markdown>

## Best Practices

### Tag Clouds

Use responsive gap for tag clouds - compact on mobile for better touch targets:

```tsx
<Wrap gap={{ base: 'xs', md: 'sm' }}>
  {tags.map(tag => (
    <span key={tag.id} className="px-3 py-1 bg-gray-100 rounded-full text-sm">
      {tag.name}
    </span>
  ))}
</Wrap>
```

### Filter Chips

Responsive spacing for filter UIs:

```tsx
<Wrap gap={{ base: 'xs', sm: 'sm', md: 'md' }}>
  {filters.map(filter => (
    <button
      key={filter.id}
      className={cn(
        'px-3 py-1 rounded-full text-sm',
        filter.active ? 'bg-blue-500 text-white' : 'border'
      )}
    >
      {filter.label}
    </button>
  ))}
</Wrap>
```

### Button Groups

Wrapping button groups that adapt to screen size:

```tsx
<Wrap gap={{ base: 'xs', md: 'sm' }}>
  <Button variant="primary">Save</Button>
  <Button variant="secondary">Cancel</Button>
  <Button variant="secondary">Reset</Button>
  <Button variant="danger">Delete</Button>
</Wrap>
```

### Skill Badges

Organized badge sections:

```tsx
<div className="space-y-4">
  <div>
    <h3>Frontend</h3>
    <Wrap gap={{ base: 'xs', md: 'sm' }}>
      {frontend.map(skill => <Badge key={skill}>{skill}</Badge>)}
    </Wrap>
  </div>
  <div>
    <h3>Backend</h3>
    <Wrap gap={{ base: 'xs', md: 'sm' }}>
      {backend.map(skill => <Badge key={skill}>{skill}</Badge>)}
    </Wrap>
  </div>
</div>
```

### Mobile-First Approach

Start with tight spacing on mobile, increase on larger screens:

```tsx
// Compact on mobile, spacious on desktop
<Wrap gap={{ base: 'xs', sm: 'sm', md: 'md', lg: 'lg' }}>
  {items.map(item => <Item key={item.id} {...item} />)}
</Wrap>
```

## Wrap vs Flex with wrap

Both can create wrapping layouts. Use **Wrap** for simple tag clouds and button groups.
Use **Flex with wrap="wrap"** when you need `justify="between"`, `around`, or `evenly`.

```tsx
// Wrap - simple wrapping, limited justify options
<Wrap gap="sm" justify="center">
  <Tag>A</Tag>
  <Tag>B</Tag>
</Wrap>

// Flex - full flexbox control
<Flex gap="sm" wrap="wrap" justify="between">
  <Tag>A</Tag>
  <Tag>B</Tag>
</Flex>
```
