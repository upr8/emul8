Stack arranges items vertically or horizontally with consistent, responsive spacing.

## Features

- **Flexible direction** - Vertical or horizontal stacking
- **Responsive gap** - Cedar-style `@breakpoint` notation for adaptive spacing
- **Split layout** - Push content to opposite ends with `splitAfter`
- **Alignment** - Control cross-axis and main-axis alignment

## Example

<Primary />
<Controls />

## Usage

```tsx
import { Stack } from "emul8";

// Vertical stack (default)
<Stack gap="lg">
  <div>Item 1</div>
  <div>Item 2</div>
</Stack>

// Horizontal stack with responsive gap
<Stack direction="horizontal" gap="sm md@md lg@lg" align="center">
  <Icon />
  <span>Label</span>
</Stack>

// Form with adaptive spacing
<Stack gap="sm md@md">
  <FormField label="Email" />
  <FormField label="Password" />
  <Button>Submit</Button>
</Stack>
```

## Responsive Gap

Use Cedar-style `@breakpoint` notation for adaptive spacing:

```tsx
// gap="base breakpoint@breakpoint"
<Stack gap="sm md@md lg@lg">
  {/* gap-2 (mobile) → md:gap-4 (tablet) → lg:gap-6 (desktop) */}
</Stack>

// Horizontal nav with responsive spacing
<Stack direction="horizontal" gap="xs sm@md lg@lg">
  <NavItem />
  <NavItem />
  <NavItem />
</Stack>
```

<Markdown>
{`
| Notation | Description |
| -------- | ----------- |
| \`md\` | Static gap (gap-4) at all sizes |
| \`sm md@md\` | gap-2 base, md:gap-4 at medium screens |
| \`sm md@md lg@lg\` | Grows with each breakpoint |
| \`md@md lg@xl\` | No base, starts at md breakpoint |
`}
</Markdown>

## Split Layout

The `splitAfter` prop pushes content after a specific index to the opposite end:

```tsx
// Header at top, footer at bottom
<Stack splitAfter={0} className="h-full">
  <header>Title</header>
  <main>Content pushed down</main>
  <footer>Footer at bottom</footer>
</Stack>

// Combine with responsive gap
<Stack splitAfter={0} gap="sm md@md" className="h-screen">
  <Header />
  <MainContent />
  <Footer />
</Stack>
```

| Prop | Type | Default | Description |

## Best Practices

### Form Layouts

Use responsive gap for forms - tighter on mobile, more breathing room on desktop:

```tsx
<Stack gap="sm md@md">
  <TextField label="Name" />
  <TextField label="Email" />
  <TextArea label="Message" />
  <Button>Submit</Button>
</Stack>
```

### Navigation Headers

Horizontal stack with responsive gap for nav items:

```tsx
<Stack direction="horizontal" gap="sm md@md lg@lg" align="center">
  <Logo />
  <nav>
    <Stack direction="horizontal" gap="xs sm@md">
      <NavLink>Home</NavLink>
      <NavLink>About</NavLink>
      <NavLink>Contact</NavLink>
    </Stack>
  </nav>
</Stack>
```

### Card Content

Stack content within cards with consistent spacing:

```tsx
<Card>
  <Stack gap="sm md@md">
    <CardHeader />
    <CardBody />
    <CardFooter />
  </Stack>
</Card>
```

### Page Layouts with Split

Combine responsive gap with splitAfter for full-page layouts:

```tsx
<Stack splitAfter={1} gap="md lg@lg" className="min-h-screen">
  <Header />
  <main className="flex-1">
    <Stack gap="sm md@md">{/* Content */}</Stack>
  </main>
  <Footer />
</Stack>
```
