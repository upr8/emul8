Cluster arranges items in a flexible, wrapping layout.

## Features

- **Natural wrapping** - Items wrap based on available space
- **Flexible gaps** - Consistent spacing between items
- **Alignment control** - Horizontal and vertical alignment
- **Slot support** - Render as child element with `asChild`

## Example

<Primary />
<Controls />

## Usage

```tsx
import { Cluster } from "emul8";

// Tag group
<Cluster gap="sm">
  <Tag>React</Tag>
  <Tag>TypeScript</Tag>
  <Tag>Tailwind</Tag>
</Cluster>

// Centered button group
<Cluster gap="md" justify="center">
  <Button>Cancel</Button>
  <Button variant="primary">Submit</Button>
</Cluster>

// Navigation items
<Cluster gap="lg" align="center">
  <NavLink>Home</NavLink>
  <NavLink>About</NavLink>
  <NavLink>Contact</NavLink>
</Cluster>
```

## Props

<Markdown>
{`
| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| \`gap\` | \`"none" \\| "xs" \\| "sm" \\| "md" \\| "lg" \\| "xl"\` | \`"sm"\` | Space between items |
| \`justify\` | \`"start" \\| "center" \\| "end" \\| "between"\` | \`"start"\` | Horizontal alignment |
| \`align\` | \`"start" \\| "center" \\| "end" \\| "baseline" \\| "stretch"\` | \`"start"\` | Vertical alignment |
| \`asChild\` | \`boolean\` | \`false\` | Render as child element |
`}
</Markdown>

## When to Use

- Groups of tags or badges
- Button groups
- Navigation links
- Any content that should wrap naturally
