Divider creates a visual separator between content.

## Features

- **Horizontal & vertical** - Both orientations supported
- **Size variants** - Thin, medium, and thick options
- **Accessible** - Uses `role="separator"` with proper ARIA attributes
- **Pure structural** - No default colors, style via className

## Example

<Primary />
<Controls />

## Usage

```tsx
import { Divider } from "emul8";

// Horizontal divider (default)
<div>
  <p>Content above</p>
  <Divider />
  <p>Content below</p>
</div>

// Vertical divider in flex container
<div className="flex items-center gap-4">
  <span>Left</span>
  <Divider orientation="vertical" className="h-4" />
  <span>Right</span>
</div>

// With color (required - no default color)
<Divider className="bg-gray-200 dark:bg-gray-700" />

// Custom color
<Divider className="bg-blue-500" />
```

## Props

<Markdown>
{`
| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| \`orientation\` | \`"horizontal" \\| "vertical"\` | \`"horizontal"\` | Divider direction |
| \`size\` | \`"sm" \\| "md" \\| "lg"\` | \`"sm"\` | Thickness of the divider |
| \`label\` | \`string\` | - | Accessible label |
`}
</Markdown>

## Styling

Divider is a **pure structural component** - it provides only the sizing and orientation without any default color. You must add a background color via `className`:

```tsx
// Basic usage with color
<Divider className="bg-gray-200 dark:bg-gray-700" />

// Vertical with color
<Divider orientation="vertical" className="h-4 bg-gray-300" />
```

## When to Use

- Separate content sections visually
- Create visual breaks in lists
- Divide navigation items
