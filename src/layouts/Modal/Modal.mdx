Modal provides a semantic dialog overlay with backdrop and proper accessibility.

## Features

- **Semantic HTML** - Uses `role="dialog"` and `aria-modal="true"`
- **Backdrop click** - Closes on backdrop click (configurable)
- **Escape key** - Closes on Escape press (configurable)
- **Body scroll lock** - Prevents background scrolling when open
- **Compound component** - Header, Body, Footer sub-components
- **Size variants** - sm, md, lg, xl, 2xl, full
- **Portal rendering** - Renders to document.body

## Usage

```tsx
import { Modal } from "emul8";
import { useState } from "react";

function MyComponent() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <button onClick={() => setOpen(true)}>Open Modal</button>

      <Modal open={open} onClose={() => setOpen(false)}>
        <Modal.Content>
          <Modal.Header>
            <Modal.Title>Confirm Action</Modal.Title>
            <Modal.Description>Are you sure you want to proceed?</Modal.Description>
          </Modal.Header>
          <Modal.Body>
            <p>This action cannot be undone.</p>
          </Modal.Body>
          <Modal.Footer>
            <button onClick={() => setOpen(false)}>Cancel</button>
            <button onClick={() => setOpen(false)}>Confirm</button>
          </Modal.Footer>
        </Modal.Content>
      </Modal>
    </>
  );
}
```

## Styling

Modal is a **pure structural component** - it handles only layout concerns (positioning, sizing, overflow) without any color or theme dependencies. Apply colors via `className`:

```tsx
// Add backdrop and content colors
<Modal open={open} onClose={onClose} className="bg-black/50">
  <Modal.Content className="bg-white dark:bg-gray-900">
    <Modal.Header className="border-gray-200 dark:border-gray-700">
      <Modal.Title>Title</Modal.Title>
      <Modal.Description className="text-gray-600 dark:text-gray-400">
        Description
      </Modal.Description>
    </Modal.Header>
    <Modal.Body>Content</Modal.Body>
    <Modal.Footer className="border-gray-200 dark:border-gray-700">
      <button>Action</button>
    </Modal.Footer>
  </Modal.Content>
</Modal>
```

## When to Use

- Confirmation dialogs
- Form dialogs
- Alert messages
- Content that requires user attention
- Workflows that need focus

## Accessibility

- Uses `role="dialog"` and `aria-modal="true"`
- Escape key closes the modal (configurable)
- Body scroll is locked when open
- Focus should be managed by the consuming application
