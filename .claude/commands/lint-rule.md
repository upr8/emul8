---
description: Interactive lint rule creation wizard
argument-hint: [create|from-pattern] [name]
---

Run the lint-rule skill from `.claude/skills/lint-rule.md` to create a new lint rule interactively.

Commands:
- (no args): Start interactive wizard
- create: Start interactive wizard
- create <name>: Create rule with specified name
- from-pattern: Create from detected pattern

Execute: $ARGUMENTS
