Switcher switches between horizontal and vertical layouts based on container width.

## Features

- **Responsive switching** - Horizontal above threshold, vertical below
- **No media queries** - Pure CSS container-based switching
- **Item limit** - Force vertical when too many items
- **Gap control** - Consistent spacing

## Usage

```tsx
import { Switcher } from "emul8";

// Basic switcher
<Switcher threshold="40rem" gap="md">
  <Card />
  <Card />
  <Card />
</Switcher>

// Switcher with item limit
<Switcher threshold="30rem" limit={4}>
  <Button>A</Button>
  <Button>B</Button>
  <Button>C</Button>
</Switcher>

// Narrow threshold for earlier switch
<Switcher threshold="20rem" gap="sm">
  <Icon />
  <Text>Label</Text>
</Switcher>
```

| \`gap\` | \`"none" \\| "xs" \\| "sm" \\| "md" \\| "lg" \\| "xl"\` | \`"md"\` | Space between items |
| \`limit\` | \`number\` | - | Force vertical if more than this many items |
`}

## How It Works

The Switcher uses a clever CSS calculation:

```css
flex-basis: calc((threshold - 100%) * 999)
```

- When container > threshold: negative value = 0 = items share space (horizontal)
- When container < threshold: large positive = items take full width (vertical)

This achieves responsive layout without media queries!
