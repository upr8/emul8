Container centers and constrains content width with responsive padding support.

## Features

- **Max-width constraint** - Multiple size presets (sm to 2xl)
- **Fluid mode** - Full-width layouts without max-width constraints
- **Responsive padding** - Object syntax for adaptive padding
- **Content centering** - Center children within container
- **Text centering** - Optional text alignment

## Usage

```tsx
import { Container, Center } from "emul8";

// Basic container with max-width
<Container size="md" padding="lg">
  <h1>Page Title</h1>
  <p>Content constrained to medium width...</p>
</Container>

// Fluid container (full-width hero)
<Container fluid padding="md">
  <HeroSection />
</Container>

// Responsive padding that adapts to screen size
<Container padding={{ base: 'sm', md: 'md', lg: 'lg' }}>
  <MainContent />
</Container>

// Container with centered children
<Container size="lg" center andText>
  <Logo />
  <h1>Welcome</h1>
</Container>
```

## Responsive Padding

Use object syntax for responsive padding across breakpoints:

```tsx
// Object syntax for responsive padding
<Container padding={{ base: 'sm', md: 'md', lg: 'lg' }}>
  {/* px-4 (mobile) → md:px-6 (tablet) → lg:px-8 (desktop) */}
</Container>

// Only apply padding at certain breakpoints
<Container padding={{ md: 'md', xl: 'xl' }}>
  {/* No base padding, md:px-6, xl:px-12 */}
</Container>
```

<Markdown>
{`
| Notation | Description |
| -------- | ----------- |
| \`"sm"\` | Static padding (px-4) at all sizes |
| \`{ base: 'sm', md: 'md' }\` | px-4 base, md:px-6 at medium screens |
| \`{ base: 'sm', md: 'md', lg: 'lg' }\` | Grows with each breakpoint |
| \`{ md: 'md', xl: 'lg' }\` | No base, starts at md breakpoint |
`}
</Markdown>

## Fluid Mode

Use `fluid` for full-width layouts without max-width constraints:

```tsx
// Full-width hero section
<Container fluid padding="md">
  <div className="bg-gradient-to-r from-blue-500 to-purple-500">
    <h1>Edge-to-Edge Hero</h1>
  </div>
</Container>

// Fluid with responsive padding
<Container fluid padding={{ base: 'xs', sm: 'sm', md: 'md', lg: 'lg' }}>
  <FullWidthBanner />
</Container>
```

## Props

<Markdown>
{`
| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| \`size\` | \`"sm" \\| "md" \\| "lg" \\| "xl" \\| "2xl" \\| "full"\` | \`"lg"\` | Max-width preset |
| \`padding\` | \`"none" \\| "xs" \\| "sm" \\| "md" \\| "lg" \\| "xl"\` or responsive object | \`"md"\` | Horizontal padding |
| \`fluid\` | \`boolean\` | \`false\` | Full-width mode (no max-width) |
| \`center\` | \`boolean\` | \`false\` | Center children horizontally |
| \`andText\` | \`boolean\` | \`false\` | Also center text content |
`}
</Markdown>

## Best Practices

### Page Layout Pattern

```tsx
// Typical page with fluid header, constrained content
<>
  <Container fluid padding={{ base: 'sm', md: 'md' }}>
    <Header />
  </Container>

  <Container size="lg" padding={{ base: 'sm', md: 'md', lg: 'lg' }}>
    <main>
      <article>...</article>
    </main>
  </Container>

  <Container fluid padding="md">
    <Footer />
  </Container>
</>
```

### Responsive Design

Start with smaller padding on mobile, increase on larger screens:

```tsx
// Mobile-first responsive padding
<Container padding={{ base: 'xs', sm: 'sm', md: 'md', lg: 'lg' }}>
  {/* Padding grows as screen size increases */}
</Container>
```

## Center Alias

`Center` is an alias for `Container`, emphasizing its centering capabilities:

```tsx
import { Center } from "emul8";

<Center size="md" center andText>
  <Logo />
  <h1>Welcome to Our App</h1>
  <p>Centered content with centered text</p>
</Center>
```
